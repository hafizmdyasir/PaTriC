# Benchmarks
PaTriC ships with a few example scripts in the folder `benchmarks` that are used not only to benchmark but also to check for bugs and errors. Currently, the simplest cases have been provided as benchmarks, but more complex cases are in development.

This page will also be updated with performance metrics across multiple cores and nodes. Stay tuned!
